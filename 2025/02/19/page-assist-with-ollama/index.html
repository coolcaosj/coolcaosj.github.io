使用PageAssist插件搭配本地ollama搭建个人AI助手

发表于 2025-02-19 更新于 2025-02-20 分类于 技术博客 ， 原创

我们使用 ollama 搭建的本地大模型服务，虽然在能力上和官方的 671b 模型相比，还有非常大的差距，但也并不是一无是处。我们可以选择合适的工具，搭配本地搭建的 ollama 服务，搭建个人的 AI 助手，来实现一些创造力没那么强的一些 AI 助手任务。

ollama 服务搭建

ollama 搭建的本地大模型服务，可以参阅博客 《使用 ollama 本地部署 deepseek 大模型》 。

PageAssist 插件安装配置

PageAssist 是一个开源的 Chrome 插件（也支持火狐），其 github 地址为： https://github.com/n4ze3m/page-assist。

对其源码感兴趣的，可以从其官方 github 上阅读其源码。

要安装 PageAssist 插件，需要从 chrome 扩展商店下载安装。地址为 https://chromewebstore.google.com/detail/page-assist-%E6%9C%AC%E5%9C%B0-ai-%E6%A8%A1%E5%9E%8B%E7%9A%84-web/jfgfiigpkhlkbnfnbobbkinehhfdhndo。

安装完成后，会在 chrome 浏览器的扩展图标上显示 PageAssist 图标。

PageAssist 配置及使用

PageAssist 主页大致如下：

其布局和一些 AI 工具类似，就是一个聊天窗口，在此可以与大模型对话。

在对话之前，我们需要先进行大模型的配置。

点击右上角的配置按钮，打开配置页面。

左侧菜单栏为可配置的菜单选项，右侧为具体的配置项目。

这里我们先选择 Ollama 设置 ，打开后会显示如下界面。

这里重要的就是配置 ollama 服务地址，其他的配置可以不用改动，也可以按需修改即可，配置完成后，一定要点击 保存 按钮。

配置完成后，可以返回到首页，如果显示如下，则说明已经配置 ollama 成功。

此时就可以使用 PageAssist 与 ollama 进行对话了。

PageAssist 功能

PageAssist 是一个功能相对来说比较齐全的 AI 客户端，除了可以链接本地的 ollama 服务，也可以接入其他第三方的在线大模型，如 deepseek。
除此之外，即使是本地部署的 ollama 服务，也可以搭配 PageAssist 的在线搜索服务，以及知识库功能，来实现更多的 AI 助手任务。

PageAssist 的在线搜索服务

使用在线搜索服务时，需要先去设置中的一般设置里，设置一下管理网络搜索。

这里建议将搜索引擎改为 google，总搜索结果设置为 5-10 即可，多了会使得速度变慢。

点击保存。

回到首页对话界面，在对话时，打开搜索互联网开关。

此时再对话时，PageAssist 会先搜索互联网，然后将搜索结果给到大模型，大模型会对搜索结果进行整理归纳，最终得到的结果会在对话窗口上显示。

知识库

PageAssist 还支持上传文档作为知识库，然后在大模型中对知识库的内容进行整理分析，帮助用户对知识库的知识进行归纳汇总。

要开启知识库功能，需要做如下设置：

  1. RAG 设置。需要一个文本嵌入模型来对文本进行嵌入，如果是使用本地的 ollama 服务，可以使用 mxbai-embed-large 模型。
    其余的设置可以不用改动，也可以按需修改即可。
  2. 管理知识：添加知识库文档，支持纯文本文件，PDF 文档，csv，markdown 文档等等，上传后会自动添加到嵌入模型中。

设置完成后，返回首页。

要使用知识库，点击输入框的这个按钮，选择相应的知识库，然后输入对应的问题即可，大模型会对知识库进行搜索，然后给出相关的答案。

其他

除此之外，PageAssist 还支持其他的一些功能，比如通过管理提示词，搭建不同的 Agent 做不同的任务。
支持 OpenAi 兼容的 API，这样如果你有其他三方 API，可以直接在 PageAssist 上使用。
